### What's New in v1.9.2

### Security
- **Hardened zip extraction against zip-slip** — replaced the substring `..` check with proper component-based validation; rejects absolute paths, parent-dir traversals, and Windows drive prefixes, then defense-in-depth verifies the joined path stays inside the destination
- **`save_text_file` no longer accepts a frontend-supplied path** — the native save dialog now opens inside Rust so a compromised renderer cannot use the command as an arbitrary file write primitive
- **macOS notification text passed to `osascript` via argv** — title and body are process arguments instead of embedded in AppleScript source, eliminating injection where backticks, `$`, parentheses, or newlines in a notification could break out of the string literal
- **AES-GCM nonce builder rejects `u64::MAX`** — defense-in-depth in the QR pairing crypto so a future caller incrementing the counter cannot wrap to 0 and reuse a nonce
- **Content-Security-Policy enabled** in production builds (was `null`); restricts script/style/connect sources to `'self'` plus the Tauri IPC URLs
- **Trimmed unused Tauri capabilities** (`opener:default`, `notification:default`, `process:allow-exit`) — shrinks the IPC attack surface
- **All third-party GitHub Actions pinned to commit SHAs** — closes the floating-tag supply-chain risk where a moved tag could silently change CI behaviour
- **`cargo-audit` pinned to `0.22.1`** in the audit workflow so an unsolicited cargo-audit release cannot land in CI without intent
- **QR code rendered via `<img>` + data URL** instead of `dangerouslySetInnerHTML` — closes a future-XSS-shaped pattern even though the SVG itself is generated by a trusted backend crate

### Added
- **PR Check CI workflow** (`.github/workflows/pr-check.yml`) — `tsc`, `npm test`, `npm run build`, and `cargo test` run automatically on every pull request and push to `main`
- **Audit CI workflow** (`.github/workflows/audit.yml`) — `npm audit` and `cargo audit` run on PRs, on push to `main`, and weekly via cron; non-blocking, reports advisory matches as warnings
- **Dependabot configuration** (`.github/dependabot.yml`) — weekly dep-bump PRs for `github-actions`, `npm`, and `cargo`; Tauri runtime packages and React + types grouped to avoid PR fragmentation

### Changed
- **TypeScript bumped 5.8.3 → 6.0.3**
- **Rust crates bumped to next major** — `sha2` 0.11, `hkdf` 0.13, `socket2` 0.6 (the latter renamed `set_ttl` → `set_ttl_v4`, updated in the raw mDNS path)
- **All other npm + cargo minor/patch deps bumped** to their latest within the existing major
- **CI release-asset poll loop replaces `sleep 15`** in the updater-bundle job — polls `gh release view` for the four expected asset suffixes with a 180s hard cap; anchored regex matches avoid stray `*.AppImage.tar.gz` from a previous run satisfying the `*.AppImage` requirement
- **Magic timing constants named** at module level across `App.tsx`, `useDeviceState.ts`, and `Toast.tsx`

### Fixed
- **Logs capped at 1000 entries** — long sessions no longer balloon memory or slow re-renders; `LogPanel` already capped display to ~200, this caps the underlying array
- **Drag-drop listener cleanup race on fast unmount** — captured-ref pattern replaces `unlisten.then(fn => fn())` so a remount before the promise resolves cannot leak the listener
- **Stale device-details fetches discarded on device list churn** — auto-fetch effect creates an `AbortController` per run; results from a torn-down effect no longer overwrite fresh state, while a per-serial in-flight guard prevents redundant ADB invocations
- **Device-tracking fallback now visible in the log panel** — when `adb track-devices` is unavailable, users see a warning explaining polling has kicked in instead of silent slowdown
- **Toast and operation-progress timers tracked and cleared on unmount** — prevents `setState` after teardown when a fast unmount occurs mid-animation
- **`release.mjs` flag parsing** — `--skip-tests` works in any position; previously a misplaced flag could be silently treated as the version arg
- **`as any` cast on Tauri drag-drop payload removed** — Tauri 2's typed `DragDropEvent` already narrows correctly after the discriminator check
- **Surfaced `osascript` non-zero exit codes as errors** — `Command::output()` only fails on spawn errors, so notification failures (permission denied, AppleScript runtime errors) now reach the frontend instead of silently returning success
